# 🧾 Problem Statement – Multi-Cloud Cost Monitor

## 1. Background

Cloud platforms offer cost and usage reports individually, but DevOps teams and FinOps engineers struggle with unified visibility across multiple providers.

## 2. The Problem

Organizations using AWS, Azure, and GCP often:

- Manually check each portal to monitor costs
- Lack central visibility into daily/monthly usage
- Struggle to set alerts across cloud boundaries
- Overspend due to delayed reporting

## 3. Why This Project?

- Learn how to interact with billing APIs in all major clouds
- Automate cost collection, processing, and alerting
- Use DevOps tooling to build a CI/CD pipeline
- Apply infrastructure as code to provision resources

## 4. Who Is It For?

- DevOps engineers
- FinOps and CloudOps teams
- Small companies managing cloud costs
- Anyone using multi-cloud setup

## 5. Goals

- Authenticate and pull usage data from AWS, Azure, and GCP
- Normalize cost data and store it (CSV or database)
- Visualize trends or email daily/weekly reports
- Trigger alerts if thresholds are crossed
